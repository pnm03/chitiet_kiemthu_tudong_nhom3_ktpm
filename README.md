# Chi tiết kiểm thử tự động nhóm 03

Kho lưu trữ này dùng để chia sẻ các file phục vụ kiểm thử tự động hộp trắng bằng Jest.

## Cấu trúc thư mục

- `Hàm kiểm thử`: chứa mã nguồn của 3 hàm được chọn để kiểm thử.
- `Mã cài đặt kiểm thử`: chứa mã cài đặt ca kiểm thử Jest tương ứng với từng hàm.
- `Kết quả kiểm thử`: thư mục để bổ sung kết quả kiểm thử sau.

## Danh sách hàm

- Hàm 1: `validateStockBeforeCheckout()`
- Hàm 2: `handleInputChange()`
- Hàm 3: `deleteInvoice()`
